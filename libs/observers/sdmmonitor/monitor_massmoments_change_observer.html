Monitor Massmoments Change Observer¶

Header file: <libs/observers/sdmmonitor/monitor_massmoments_change_observer.hpp> [source]

The observers that write the mass-moment changes recorded by Monitor Massmoments Change to a dataset, via DoSDMMonitorObs.

Functions

template<typename Dataset, typename Store>
inline Observer auto MonitorMassMomentsChangeObserver(const unsigned int interval, Dataset &dataset, Store &store, const size_t maxchunk, const size_t ngbxs)¶

Constructs an observer which writes data monitoring the mass moments during microphysics and super-droplet motion to arrays with a constant observation timestep “interval”.

Template Parameters:

Store – Type of store for dataset.

Parameters:

  • interval – Observation timestep.

  • dataset – Dataset to write time data to.

  • store – Store which dataset writes to

  • maxchunk – Maximum number of elements in a chunk (1-D vector size).

  • ngbxs – The number of gridboxes.

Returns:

Constructed type satisfying observer concept.

template<typename Dataset, typename Store, typename MonitorXarraysType, typename MonitorViewsType>
class DoMonitorMassMomentsChangeObs¶
#include <monitor_massmoments_change_observer.hpp>

Class for functionality to observe data from a mass moments monitor of a SDM process at the start of each timestep and write it to a Zarr array in an Xarray dataset.

Template Parameters:

  • Store – Type of store for dataset.

  • MonitorXarraysType – Type for xarrays for mass moments in dataset.

  • MonitorViewsType – Type for views which calculate mass moments for xarrays.
