Optional Config Params¶

Header file: <libs/configuration/optional_config_params.hpp> [source]

Configuration parameters that are optional (fall back to a default if not given in the YAML file), controlling e.g. which coupled dynamics, collision kernel, or breakup scheme is used.

struct OptionalConfigParams¶
#include <optional_config_params.hpp>

Struct storing optional configuration parameters for CLEO.

Optional means parameters have default values and therefore need not be set upon construction. Default values are not intended to be used and may caused model errors at runtime.
