Required Config Params¶

Header file: <libs/configuration/required_config_params.hpp> [source]

Configuration parameters every Cleo run must supply (domain, timesteps, input/output file paths).

struct RequiredConfigParams¶
#include <required_config_params.hpp>

Struct storing required configuration parameters for CLEO.

Required means parameters have no default values and therefore must be set upon construction.
