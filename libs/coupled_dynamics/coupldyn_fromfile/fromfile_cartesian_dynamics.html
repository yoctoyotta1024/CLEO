FromFile Cartesian Dynamics¶

Header file: <libs/coupldyn_fromfile/fromfile_cartesian_dynamics.hpp> [source]

A CoupledDynamics (see ../runcleo/coupleddynamics) reading thermodynamics and wind fields for a Cartesian domain from binary files (see ../../cleopy/thermobinary_src/thermobinary_src), one timestep at a time.

Note

This header also defines an internal helper struct called CartesianDynamics that holds the thermodynamics/wind arrays read from file (constructed internally by FromFileDynamics below). YAC Cartesian Dynamics defines an unrelated struct of the same name for the YAC coupling option. Because Sphinx’s C++ domain cannot distinguish two identically-named, non-namespaced structs, we have given neither struct a documented API entry; please see the source code itself for the CartesianDynamics API for the struct in fromfile_cartesian_dynamics.hpp.
