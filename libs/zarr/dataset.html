Dataset¶

Header file: <libs/zarr/simple_dataset.hpp> [simple dataset source]

SimpleDataset is the Zarr dataset implementation used for a run with a single MPI process (e.g. a standalone or one-way-coupled run): every variable is written by one process, with no collective/parallel I/O.

template<typename Store>
class SimpleDataset¶

A class representing a dataset made from a Zarr group (i.e. collection of Zarr arrays) in a storage system.

This class provides functionality to create a dataset as a group of arrays obeying the Zarr storage specification version 2 (https://zarr.readthedocs.io/en/stable/spec/v2.html) that is also compatible with Xarray and NetCDF.

Template Parameters:

Store – The type of the store object used by the dataset.

Header file: <libs/zarr/collective_dataset.hpp> [collective dataset source]

CollectiveDataset is the Zarr dataset implementation used for a run split across multiple MPI processes (e.g. a two-way-coupled run with its own domain decomposition, see Cartesian Decomposition): each process writes only the data for the gridboxes/super-droplets it owns, coordinated as a single collective write.
