Coupldyn CVODE Module
=======================

This module of Cleo implements a ``CoupledDynamics`` option (see
:doc:`../runcleo/coupleddynamics` and :doc:`../../intro/coupling`) that solves a 0-D thermodynamic
ODE system with the `CVODE <https://computing.llnl.gov/projects/sundials/cvode>`_ solver,
two-way coupled to Cleo's microphysics.
