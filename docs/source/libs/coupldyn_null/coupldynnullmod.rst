Coupldyn Null Module
======================

This module of Cleo implements the "null" ``CoupledDynamics``/``CouplingComms`` pair (see
:doc:`../runcleo/coupleddynamics` and :doc:`../runcleo/couplingcomms`): used for a standalone SDM
run with no coupled dynamics at all (gridbox thermodynamics stay fixed at their initial values).
