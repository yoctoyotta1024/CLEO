InitGbxsNull
==============

Header file: ``<libs/initialise/initgbxsnull.hpp>``
`[source] <https://github.com/yoctoyotta1024/CLEO/blob/main/libs/initialise/initgbxsnull.hpp>`_

An ``InitialConditions`` (see :doc:`initialconditions`) "null" implementation for a gridbox's
thermodynamic initial conditions, used when they instead come from a ``CoupledDynamics`` (see
:doc:`../runcleo/coupleddynamics` and :doc:`../../intro/coupling`) at the first coupling step.
