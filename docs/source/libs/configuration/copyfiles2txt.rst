Copy Files To Txt
===================

Header file: ``<libs/configuration/copyfiles2txt.hpp>``
`[source] <https://github.com/yoctoyotta1024/CLEO/blob/main/libs/configuration/copyfiles2txt.hpp>`_

Copies the contents of the run's configuration/source files into a single setup ``.txt`` file
alongside the output dataset, so a run's exact configuration is preserved with its output.
