CFL Criteria
==============

Header file: ``<libs/gridboxes/cfl_criteria.hpp>``
`[source] <https://github.com/yoctoyotta1024/CLEO/blob/main/libs/gridboxes/cfl_criteria.hpp>`_

Checks the Courant-Friedrichs-Lewy (CFL) criterion for super-droplet motion: that a
super-droplet cannot move more than one gridbox per (sub-)timestep.
