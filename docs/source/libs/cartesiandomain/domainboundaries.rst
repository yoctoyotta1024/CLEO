Domain Boundaries

Header file: ``<libs/cartesiandomain/domainboundaries.hpp>``
`[source] <https://github.com/yoctoyotta1024/CLEO/blob/main/libs/cartesiandomain/domainboundaries.hpp>`_

Functions for detecting when a super-droplet has moved beyond a gridbox's boundary in a
Cartesian domain, and for finding the neighbouring gridbox on a finite or periodic domain.
