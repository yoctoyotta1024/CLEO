Coupldyn FromFile Module
==========================

This module of Cleo implements a ``CoupledDynamics`` option (see
:doc:`../runcleo/coupleddynamics` and :doc:`../../intro/coupling`) that one-way "piggybacks" on
thermodynamics and wind fields read in from file for a Cartesian domain, rather than running a
live dynamical core.
